1. 关于我们

感谢您选择使用鼠传。

鼠传是一款运行于 HarmonyOS（鸿蒙）平台的远程控制应用，支持手机、平板与鸿蒙电脑（2in1）形态，由鼠传开发团队（以下简称"我们"）提供与运营。

本应用通过 WiFi 局域网（TCP）或蓝牙（SPP）将您的设备作为触控板与键盘，控制运行在 Windows 上的配套主机程序，实现键鼠输入转发。

鼠传用户服务协议是我们与用户（以下简称"您"）关于使用鼠传服务所订立的有效协议。

4. 服务内容

鼠传是我们为您提供的设备间键鼠输入转发服务，您可通过本平台实现以下操作：

（1）连接管理：选择 WiFi 局域网或蓝牙连接方式，配置目标 Windows 主机地址与端口，管理已配对设备并查看连接状态；

（2）触控板控制：以独立浮动窗口形式提供触控板，支持单击、双指滚动、双指点按右键、长按拖拽、三指横滑切换任务等手势，并可调节窗口尺寸；

（3）虚拟键盘：以独立浮动窗口形式提供 QWERTY 键盘，支持按键按下与长按操作；

（4）鼠标桥接：通过双屏分区隐喻将您的设备边缘作为进入 Windows 屏幕的入口，实现本地与 Windows 屏幕之间的连续指针操控，并支持物理键盘按键转发；

（5）使用偏好：配置自然滚动方向、Windows 相对方位、桥接速度与滚轮速度等个人偏好，并自动记住上次成功的连接信息；

（6）配套主机程序：上述功能的完整实现还需要在您的 Windows 设备上自行安装并运行本项目的配套主机程序（随项目代码库公开发布），该程序由您自行部署、自行运行，其安装与运行环境由您负责。

5. 权限说明

为保障鼠传服务的正常运行，我们会申请以下权限：

5.1 蓝牙权限（ohos.permission.ACCESS_BLUETOOTH / ohos.permission.DISCOVER_BLUETOOTH）：用于发现并连接您已配对的 Windows 设备，通过蓝牙向该设备转发键鼠输入。其中蓝牙访问权限需要您在运行时授权，您可以随时在系统设置中关闭该权限；

5.2 网络权限（ohos.permission.INTERNET）：用于通过 WiFi 局域网向您自行指定的 Windows 主机地址发送键鼠输入数据，并维持连接存活检测。该权限由系统自动授予；

5.3 窗口透明权限（ohos.permission.SET_WINDOW_TRANSPARENT）：仅在鼠标桥接功能使用时，用于将窗口背景设为透明以实现沉浸式操控。该权限由系统自动授予；

5.4 振动权限（ohos.permission.VIBRATE）：用于向您提供操作反馈提示，例如鼠标桥接的返回提示与异常提醒时的短促振动。该权限由系统自动授予。

以上权限仅在对应功能使用时才会调用，我们不会在非必要场景下申请或使用任何权限。
