# 74LS245 vs 74LS373 作用详解

在 8086 **最小模式**系统中，**74LS245** 和 **74LS373** 是两片关键的支持芯片。它们共同协作，将 8086 CPU 引脚上**分时复用**的地址/数据信号，转换为系统独立的**地址总线**和**数据总线**。

- **74LS373** —— **地址锁存器**：负责"留住"地址
- **74LS245** —— **双向总线收发器**：负责"放大并双向传输"数据

---

## 一、74LS245 详解

在 8086 **最小模式**中，**74LS245** 是 **8 位双向总线收发器（Bus Transceiver）**。由于 8086 的 AD₀~AD₁₅ 引脚驱动能力很弱（约只能驱动 1 个标准 TTL 负载），而系统数据总线上要挂接内存、I/O 接口等多个芯片，因此必须使用 74LS245 对数据总线进行**双向缓冲与电气隔离**。

### 1.1 硬件配置：两片并联构成 16 位数据缓冲

8086 是 16 位数据总线，而一片 74LS245 只有 8 位，所以需要**两片并联**：

| 芯片 | 负责的数据位 | 连接 |
|------|-------------|------|
| 74LS245（U1） | AD₀~AD₇（低 8 位） | 一侧接 8086 的 AD₀~AD₇，另一侧接系统数据总线 D₀~D₇ |
| 74LS245（U2） | AD₈~AD₁₅（高 8 位） | 一侧接 8086 的 AD₈~AD₁₅，另一侧接系统数据总线 D₈~D₁₅ |

### 1.2 引脚与 8086 控制信号的连接

74LS245 的关键控制引脚只有 2 个，它们直接与 8086 最小模式提供的专用总线控制信号相连：

| 74LS245 引脚 | 功能 | 接 8086 哪个引脚 | 说明 |
|-------------|------|----------------|------|
| **DIR** | 方向控制 | **DT/R**（Data Transmit/Receive） | 决定数据流向 |
| **G**（或 $\overline{OE}$） | 输出使能（低电平有效） | **DEN**（Data Enable，低电平有效） | 控制缓冲器是否打开 |

**控制逻辑**

- **DIR = 1（高电平）**：A → B 方向，即 **CPU 向外发送数据**（写操作）
- **DIR = 0（低电平）**：B → A 方向，即 **外部向 CPU 送入数据**（读操作）
- **G = 0（低电平）**：缓冲器打开，数据可以传输
- **G = 1（高电平）**：缓冲器进入**高阻态**，数据总线被**电气隔离**

### 1.3 具体工作过程（时序配合）

8086 最小模式的总线周期通常为 T1、T2、T3、T4 四个状态：

#### 1.3.1 T1 状态 —— 地址输出期
- 8086 在 AD₀~AD₁₅ 上输出**地址信号**（此时还不是数据）。
- **ALE** 有效，将地址锁存到 **74LS373** 地址锁存器中。
- **DEN = 1（无效）**，74LS245 的 G = 1，两片芯片均处于**高阻态**，完全隔离数据总线，避免与地址信号冲突。

#### 1.3.2 T2 状态 —— 数据切换期
- AD₀~AD₁₅ 上的地址撤销，引脚浮空准备传输数据。
- **DEN = 0（有效）**，74LS245 的 G = 0，缓冲器**打开**。
- **DT/R** 根据操作类型置位：
  - **读操作**：DT/R = 0，DIR = 0，数据方向为 **B → A**（外部设备/内存 → CPU）
  - **写操作**：DT/R = 1，DIR = 1，数据方向为 **A → B**（CPU → 外部设备/内存）

#### 1.3.3 T3 / Tw 状态 —— 数据传输期
- 数据在 16 位数据总线上稳定传输。
- 74LS245 持续导通，提供足够的电流驱动能力，确保信号能到达总线上所有挂接的芯片。

#### 1.3.4 T4 状态 —— 结束期
- 数据传输完成。
- **DEN = 1**，74LS245 重新进入**高阻态**，总线被释放，等待下一个总线周期。

### 1.4 74LS245 的核心作用总结

| 作用 | 具体说明 |
|------|---------|
| **增强驱动能力** | 8086 引脚只能驱动约 1 个 TTL 负载，74LS245 可驱动数十个负载，使系统能挂接多片 RAM、ROM、I/O 接口芯片 |
| **双向传输** | 既能读（外部→CPU）也能写（CPU→外部），一片芯片解决双向问题 |
| **电气隔离** | DEN 无效时处于高阻态，将 CPU 与系统数据总线隔离，避免总线冲突和信号干扰 |
| **提高可靠性** | 减少总线反射和信号衰减，保证高速数据传输的完整性 |

### 1.5 一句话概括

> **74LS245 两片并联在 8086 最小模式的数据总线上，由 DT/R 控制传输方向，由 DEN 控制通断，起到"双向闸门 + 功率放大"的作用**，让 8086 能够可靠地驱动整个系统的数据总线。

## 二、74LS373 详解

在 8086 **最小模式**中，**74LS373** 是 **8 位透明锁存器（Transparent Latch）**，其核心作用是**地址锁存**。由于 8086 采用 **地址/数据总线分时复用（Multiplexed）** 技术，AD₀~AD₁₅ 引脚在总线周期的不同阶段既传地址又传数据，因此必须用 74LS373 将地址信号"保存"下来，才能形成独立的系统地址总线。

### 2.1 为什么必须使用 74LS373？

#### 2.1.1 8086 的引脚复用问题

8086 共有 20 根地址线（A₀~A₁₉），但引脚数量有限，采用了**分时复用**设计：

| 引脚 | 复用功能 |
|------|---------|
| AD₀~AD₁₅ | **T1 状态**：地址线 A₀~A₁₅<br>**T2~T4 状态**：数据线 D₀~D₁₅ |
| A₁₆/S₃~A₁₉/S₆ | **T1 状态**：地址线 A₁₆~A₁₉<br>**T2~T4 状态**：状态信号 S₃~S₆ |

**问题**：如果在 T1 之后不保存地址，当 AD₀~AD₁₅ 切换为数据线时，地址信息就丢失了。而内存和 I/O 设备在整个总线周期内都需要稳定的地址信号来寻址。

**解决方案**：在 T1 状态用 **ALE（Address Latch Enable）** 信号触发 74LS373，将地址"锁存"住，形成独立的、持续有效的系统地址总线。

### 2.2 硬件配置：三片并联构成 20 位地址锁存

8086 有 20 根地址线，一片 74LS373 只有 8 位，因此需要**三片**配合：

| 芯片 | 负责锁存的地址位 | 数据来源 |
|------|----------------|---------|
| 74LS373（U1） | A₀~A₇ | 8086 的 AD₀~AD₇ |
| 74LS373（U2） | A₈~A₁₅ | 8086 的 AD₈~AD₁₅ |
| 74LS373（U3） | A₁₆~A₁₉ | 8086 的 A₁₆/S₃~A₁₉/S₆ |

### 2.3 74LS373 的引脚功能与连接

#### 2.3.1 关键引脚

| 引脚 | 名称 | 功能 | 在 8086 系统中的接法 |
|------|------|------|-------------------|
| **D₀~D₇** | 数据输入 | 接收待锁存的信号 | 接 8086 的 AD₀~AD₇（或 AD₈~AD₁₅、A₁₆/S₃~A₁₉/S₆） |
| **Q₀~Q₇** | 数据输出 | 输出锁存后的信号 | 接系统地址总线 A₀~A₇（或 A₈~A₁₅、A₁₆~A₁₉） |
| **LE**（Latch Enable） | 锁存使能 | 高电平：透明（Q 随 D 变化）<br>低电平：锁存（Q 保持原值） | 接 8086 的 **ALE** 信号 |
| **$\overline{OE}$**（Output Enable） | 输出使能 | 低电平有效，控制 Q 端是否输出 | **接地（常有效）**，使锁存后的地址始终出现在地址总线上 |

### 2.4 具体工作过程（时序配合）

8086 一个总线周期通常为 T1、T2、T3、T4 四个状态：

#### 2.4.1 T1 状态 —— 地址输出期（锁存关键窗口）

- 8086 在 **AD₀~AD₁₅** 和 **A₁₆/S₃~A₁₉/S₆** 上输出**20 位地址信息**。
- **ALE 信号变为高电平**（有效）。
- 74LS373 的 **LE = 1**，芯片处于**透明模式**：Q 端实时跟随 D 端变化，即 Q = D。
- 此时，8086 输出的地址信号直接通过 74LS373 传到系统地址总线。

#### 2.4.2 T1 下降沿 / T2 状态 —— 地址锁存（关键动作）

- **ALE 信号从高变低**（下降沿）。
- 74LS373 的 **LE = 0**，芯片进入**锁存模式**。
- 在 LE 下降沿的瞬间，D 端（即 8086 输出的地址）被"冻结"保存在锁存器中。
- 此后，无论 D 端输入如何变化，**Q 端输出保持不变**，持续提供稳定的地址信号。

#### 2.4.3 T2~T4 状态 —— 数据传输期

- 8086 的 **AD₀~AD₁₅** 引脚功能切换为**数据线**（传输读写数据）。
- 但系统地址总线上的 **A₀~A₁₅** 仍由 74LS373 保持，内存/I/O 设备继续根据这个稳定地址进行寻址。
- A₁₆/S₃~A₁₉/S₆ 引脚也切换为状态信号 S₃~S₆，但 A₁₆~A₁₉ 同样被锁存器保存。

### 2.5 74LS373 的核心作用总结

| 作用 | 具体说明 |
|------|---------|
| **地址分离** | 将 8086 分时复用的 AD₀~AD₁₅ 分离为独立的地址总线 A₀~A₁₅ 和数据总线 D₀~D₁₅，解决"一根线两用"的矛盾 |
| **地址保持** | 在 T1 之后，CPU 引脚转为数据传输时，锁存器继续向系统提供稳定的地址信号，确保内存/I/O 设备不会"找不到路" |
| **形成完整 20 位地址** | 三片 74LS373 配合，提供 8086 所需的全部 20 位地址总线（A₀~A₁₉），支持 1MB 寻址空间 |
| **提高驱动能力** | 74LS373 的输出端比 8086 引脚具有更强的负载驱动能力，可带动更多内存和 I/O 芯片 |

### 2.6 最小模式地址/数据总线形成示意图

```
8086 CPU
├─ AD₀~AD₇ ──┬──→ 74LS373（U1）──→ 系统地址总线 A₀~A₇
│            └──→ 74LS245（U1）──→ 系统数据总线 D₀~D₇
├─ AD₈~AD₁₅ ─┬──→ 74LS373（U2）──→ 系统地址总线 A₈~A₁₅
│            └──→ 74LS245（U2）──→ 系统数据总线 D₈~D₁₅
├─ A₁₆/S₃~A₁₉/S₆ ──→ 74LS373（U3）──→ 系统地址总线 A₁₆~A₁₉
└─ ALE ─────────────→ 三片 74LS373 的 LE 端（并联）
```

### 2.7 一句话概括

> **74LS373 在 8086 最小模式中的作用是：在 ALE 信号控制下，于 T1 状态捕获并锁存 8086 输出的地址信息，形成持续稳定、独立的 20 位系统地址总线，使 CPU 引脚在后续状态切换为数据线时，内存和 I/O 设备仍能可靠寻址。**

## 三、74LS245 与 74LS373 对比

| 对比项 | **74LS245** | **74LS373** |
|--------|------------|------------|
| **本质** | 双向总线收发器（Bus Transceiver） | 透明锁存器（Transparent Latch） |
| **核心作用** | 数据总线的双向缓冲与驱动 | 地址信号的锁存与保持 |
| **接入总线** | 系统**数据总线** D₀~D₁₅ | 系统**地址总线** A₀~A₁₉ |
| **使用数量** | 2 片（拼成 16 位） | 3 片（拼成 20 位） |
| **关键控制引脚** | DIR（方向）、G（使能） | LE（锁存使能）、$\overline{OE}$（输出使能） |
| **接 8086 控制信号** | **DT/R**、**DEN** | **ALE** |
| **数据传输方向** | **双向**（读/写均使用） | **单向**（只锁存输入到输出） |
| **工作时段** | T2~T4（数据传输期） | T1 上升沿捕获，T1 下降沿锁存 |
| **高阻态** | 支持（G=1 时进入高阻） | 不支持（保持锁存值） |
| **解决的核心问题** | CPU 驱动能力弱，无法带动多设备 | 地址/数据总线分时复用，T1 后地址丢失 |

## 四、协作关系总结

```
       8086 CPU（最小模式）
              │
   ┌──────────┴──────────┐
   │                     │
   ▼                     ▼
74LS373 × 3            74LS245 × 2
（地址锁存）           （数据收发）
   │                     │
   ▼                     ▼
系统地址总线 A₀~A₁₉   系统数据总线 D₀~D₁₅
   │                     │
   └──────────┬──────────┘
              ▼
       内存 / I/O 设备
```

- **74LS373** 把 CPU 引脚上的"瞬时地址"留住，形成**永久稳定**的系统地址总线；
- **74LS245** 把 CPU 引脚上的"弱驱动数据"放大并双向搬运，形成**强驱动**的系统数据总线；
- 两者在 **ALE、DT/R、DEN** 等控制信号的配合下，与 8086 CPU 共同构成完整的**最小模式三总线系统**（地址总线、数据总线、控制总线）。
