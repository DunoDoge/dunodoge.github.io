# C++ Primer Plus 阅读拾遗

## 第 2 章 开始学习 C++

### 2.1 进入 C++

首先给出一段最简单的 Hello World 代码：

```cpp
// hello.cpp -- displays a message

#include <iostream>
int main()
{
    using namespace std;
    cout << "Hello World!" << endl;
    return 0;
}
```

来看 `main()` 函数的基本结构：函数头（函数类型接函数名）+ 函数定义（函数体，return 结束函数结尾）

很简单吧？再逐行分析：

- 第 1 行，注释，`//` 开头，C++ 风格，在一行内显示。对比 C 风格注释：用 `/**/` 包裹，可以跨越多行
- 第 2 行，空行，自由使用，见 [C/C++ 空行使用规范](cpp-empty-line-usage.md)，核心是按逻辑等距分块，避免连续空行
- 第 3 行，`include` 语句，`iostream` 是包含文件，也称头文件——包含在代码起始处。
    - C 的传统：头文件是否扩展名 h，例如 `math.h`
    - C++ 的风格：没有扩展名；从 C 迁移到 C++，去掉扩展名再加上 c 前缀，例如 `cmath`
    - 纯粹的 C++ 头文件，去掉 h 不仅是形式上的变化，没有 h 的头文件可以包含*名称空间*
- 第 4 行，`main()` 函数头，作为程序和操作系统之间的桥梁
- 第 5 行，左花括号 `{`，标志函数体开始
- 第 6 行，`using` 编译指令，使用名称空间，让 `cout`、`endl` 等名称可直接使用，详见 [C++ 名称空间](cpp-namespace.md)
- 第 7 行，`return` 函数返回语句，值 0 表示程序正常结束
- 第 8 行，右花括号 `}`，标志函数体结束

深入理解代码，也能挖掘出很多看似不起眼的知识！
